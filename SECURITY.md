# Security Policy

## Responsible use

Use Quietprint only on authorized networks. Do not use it for active probing, traffic modification, payload collection, exploitation, or individual tracking.

## Reporting vulnerabilities

Please report security vulnerabilities privately to the maintainers through the repository's private security-advisory mechanism. If that is unavailable, open an issue that contains no sensitive technical details and request a private contact channel.

Include reproduction steps, affected versions, expected behavior, and the impact. Please allow reasonable time for investigation and a coordinated disclosure before public release.
